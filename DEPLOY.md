# Deployment Guide

Bu proje production'a deploy edilmeye hazırdır. Aşağıdaki adımları takip edin:

## 🚀 Deployment Seçenekleri

### 1. Vercel (Önerilen - En Kolay)

1. **Vercel hesabı oluşturun**: https://vercel.com
2. **GitHub'a push edin**:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git remote add origin <your-github-repo-url>
   git push -u origin main
   ```
3. **Vercel'e bağlayın**:
   - Vercel dashboard'a gidin
   - "New Project" tıklayın
   - GitHub repo'nuzu seçin
   - Environment variables ekleyin (`.env.local` içindekiler)
   - Deploy edin!

### 2. Netlify

1. **Netlify hesabı oluşturun**: https://netlify.com
2. **Build ayarları**:
   - Build command: `npm run build`
   - Publish directory: `.next`
   - Environment variables: `.env.local` içindekileri ekleyin

### 3. Docker

1. **Dockerfile oluşturun** (zaten var)
2. **Build edin**:
   ```bash
   docker build -t disfircasi .
   docker run -p 3000:3000 disfircasi
   ```

### 4. Standalone Build (VPS/Server)

1. **Build edin**:
   ```bash
   npm run build
   npm start
   ```

## 🔒 Firebase Security Rules

Firebase Firestore ve Storage için security rules'ları kontrol edin:

**Firestore Rules:**
```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Categories - herkes okuyabilir, admin yönetebilir (silme dahil)
    match /categories/{categoryId} {
      allow read: if true;
      allow write, delete: if request.auth != null;
    }

    // Products - herkes okuyabilir, admin yönetebilir
    match /products/{productId} {
      allow read: if true;
      allow write, delete: if request.auth != null;
    }
    
    // Site content - herkes okuyabilir, admin yönetebilir
    match /siteContent/{contentId} {
      allow read: if true;
      allow write, delete: if request.auth != null;
    }
    
    // Orders - herkes sipariş oluşturabilir, admin okuyup yönetebilir
    match /orders/{orderId} {
      allow create: if true;
      allow read, update, delete: if request.auth != null;
    }

    // Contacts - herkes yazabilir, admin okuyabilir
    match /contacts/{contactId} {
      allow create: if true;
      allow read, write, delete: if request.auth != null;
    }

    // Settings & Coupons
    match /settings/{settingId} {
      allow read: if true;
      allow write, delete: if request.auth != null;
    }
    match /coupons/{couponId} {
      allow read: if true;
      allow write, delete: if request.auth != null;
    }

    // Admin koleksiyonu
    match /admin/{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}
```

**Storage Rules:**
```javascript
rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /{allPaths=**} {
      allow read: if true;
      allow write: if request.auth != null;
    }
  }
}
```
